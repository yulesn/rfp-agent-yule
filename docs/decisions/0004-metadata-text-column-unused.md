# 0004. 메타데이터 CSV 의 `텍스트` 컬럼은 사용하지 않는다
- 상태: 확정됨
- 날짜: 2026-11-11
- 결정자: Yule

## 맥락
`data/raw/data_list.csv` 에는 문서 본문처럼 보이는 `텍스트` 컬럼이 있다. 데이터 탐색(`docs/research/2026-11-11-데이터-탐색.md`)에서
이 컬럼이 중앙값 약 2.8천자로 파서가 뽑은 본문(중앙값 약 7.5만자)의 일부일 뿐이고 파서 결과의 앞부분과도 일치하지 않음을 확인했다.
Yule이 이 컬럼은 대부분 각 문서의 목차라고 알려 주었다.

## 후보 비교
| 후보 | 장점 | 단점 |
| --- | --- | --- |
| A. `텍스트`를 색인 본문으로 사용 | 파싱 불필요 | 목차 수준이라 본문 질의에 답할 근거가 없음 |
| B. `텍스트`를 목차/보조 정보로 병행 사용 | 구조 힌트 가능 | 파서로도 얻을 수 있고 형식이 불규칙해 이득이 작음 |
| C. 사용하지 않음 (채택) | 단순함, 출처 일관성 | 파싱 실패 문서(케빈랩 1건)는 대체 본문이 없음 |

## 결정
`텍스트` 컬럼은 사용하지 않는다. 본문은 `data/raw/` 의 원본 파일(HWP/PDF)을 직접 파싱한다. 메타 로더는 이 컬럼을 버린다.

## 근거
- 본문 질의응답과 출처 인용에는 전체 본문이 필요하다.
- 컬럼 내용이 목차 위주라 검색·평가에 기여하는 정보가 거의 없다.

## 영향 / 되돌리는 방법
- `load_metadata` 는 `텍스트` 컬럼을 제거한다. `파일형식` 은 확장자와 중복이라 선택적으로만 유지.
- 파서가 실패한 1건은 Phase 1-2 에서 별도 처리 방침을 정한다.
- 되돌리려면 로더에서 컬럼 제거만 빼면 된다.
