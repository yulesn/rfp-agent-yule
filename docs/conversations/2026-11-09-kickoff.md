# 2026-11-09 킥오프: 솔로 진행 방식과 플랜

## 배경
팀 프로젝트(RFP RAG 에이전트)를 혼자서도 전 파트를 구현해 보기로 함. 팀 레포는 구조만 참고.

## 과제와 요청 사항 (요약)
- 과제: 100개 실제 RFP(hwp, pdf) + 메타데이터로 Q&A 가능한 시스템. 단순 RAG가 아니라 **RAG가 포함된 에이전트**
  - 1차(베이스라인): LangChain 에이전트 또는 LangGraph로 RAG 수행
  - 2차(최종): B2G 입찰 컨설팅에 필요한 기능을 도구/노드로 정의한 복합 에이전트
  - 평가 방식·지표를 직접 선정, 의사결정 과정이 보고서/발표에 드러나야 함
- 멘토 조언 (우선순위)
  1. LLM 활용(AI 에이전트): 무조건. gemini flash, openrouter 등, artificialanalysis 리더보드 참고
  2. 클라우드 인프라: 거의 무조건. AWS 최고, 여의치 않으면 vercel/supabase. draw.io 아키텍처 다이어그램을 뽑고 이해하는 것이 중요
  3. PDF 청킹: 한 번씩은 해보기 (전처리 노가다)
  4. RAG(벡터DB, 임베딩, 알고리즘): 테스트셋 직접 구축, 평가 시스템 설계(정량, LLM-as-judge, 속도, 비용)
  5. Jev 도입: RAG 필요 여부 판단, 가드레일 쪽
  - 웹 프론트: AI로. designmd.me/remix, styles.refero.design 참고, 이미지 모델로 시안 5개 → 컨펌 → 작업
  - 웹 백엔드: AI로. 채용공고 긁어서 많이 쓰는 기술스택으로
  - 분산처리 아키텍처 설계 및 스트레스 테스트 (클라우드+백엔드)
- 진행 규칙
  1. 파트 전부 구현. 플래닝/컨펌은 Opus, 실구현은 Sonnet
  2. Yule과 얘기한 내용, 시행착오는 전부 레포에 기록
  3. GitHub 레포 + 하네스 환경 구축. 기술스택과 기획은 Yule과 함께 확정
  4. 스킬/에이전트 조사해서 세팅
  5. 플랜 짜고 리뷰해서 공유 → Yule 컨펌 후 실작업

# 2026-11-11 이어서: v0.1 플랜 질문에 대한 Yule 답변

## Yule 답변 (요약)
- 개인 포트폴리오 프로젝트라 마감일 없음
- 유료 API와 AWS는 최소한으로. AWS 전체 배포 여부는 미정
- RFP 파일은 구글 드라이브에 있음. 프로젝트 구조가 잡히면 내려받을 예정
- Jev: 문장을 생성하지 않고 바로 로직을 실행하는 모델로 알고 있으나 정확하지 않음. 쓸 경우 조사 필요
- Docker는 쓸 수 있지만 SQL 서버 없이 Chroma만 쓰는 쪽을 선호

- 레포는 Yule이 `yulesn/rfp-agent-yule` 로 생성

## Claude 제안 / 반영 (플랜 v0.2)
- Chroma만 사용 동의: 100건 규모에선 SQL 서버가 불필요. 문서 단위 조건 검색은 메타데이터 CSV + pandas → ADR 0003
- 비용 최소: LLM은 Gemini 무료 티어 기본, 임베딩은 로컬(BGE-M3/KURE), 배포는 무료 호스팅 + AWS는 다이어그램·Terraform·짧은 검증 배포
- 부하 테스트는 로컬 docker-compose + LLM 목 응답 모드로 비용 없이
- Jev: Phase 7에서 조사. 설명상 Meta JEPA 계열(비생성형, 임베딩 예측)일 가능성 → 추정, 확인 필요
