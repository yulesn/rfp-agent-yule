# 의존성 설치가 매우 오래 걸리고 .venv 가 6GB
- 날짜: 2026-11-11 / Phase 1 / 관련 파일: `pyproject.toml`, `uv.lock`

## 증상
`uv add langchain ... sentence-transformers ...` 를 한 번에 실행했더니 10분 제한을 넘겨 백그라운드로 전환되었고, 완료까지 약 20분이 걸렸다. 끝난 뒤 `.venv` 가 약 6GB 였다.

## 시도한 것
- 실패한 설치는 없었음(에러 없이 완료). 대기만 했다.
- 중간에 `uv.lock` 은 먼저 생성되고 실제 설치(다운로드)가 뒤에서 오래 진행되었다.

## 원인
`sentence-transformers` 가 `torch` 를 끌고 오고, Linux 기본 torch 휠은 CUDA 라이브러리(nvidia-*)를 함께 받는다. 로컬 임베딩(BGE-M3, ADR/플랜 3절 6번)을 CPU 로 쓸 예정이라도 기본 설치는 GPU 용 패키지까지 포함한다.

## 해결
그대로 두고 설치를 끝냈다. 테스트는 무거운 라이브러리(torch, chromadb 등)를 모듈 import 시점이 아니라 함수 안에서 lazy import 하도록 스텁을 작성해서 `uv run pytest` 가 2초 안에 끝난다.
용량이 문제가 되면(CI, 배포 이미지) CPU 전용 torch 인덱스(`[tool.uv.sources]` + pytorch cpu index)를 쓰는 것을 Phase 4 배포 때 검토한다. 임의로 바꾸지 않고 Yule 확인 후 결정.

## 배운 점
로컬 임베딩을 쓰면 의존성 용량(약 6GB)과 설치 시간이 배포/CI 비용이 된다. CPU 전용 휠 선택은 배포 단계의 결정 사항이다.
